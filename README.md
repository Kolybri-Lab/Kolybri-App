## About Kolybri

Kolybri is a reimagined mobile companion for EcoleDirecte.
The whole experience has been rebuilt from the ground up to give students a smoother, faster and more pleasant way to keep track of school life on their phone.
Enjoy the most-requested features along with a bunch of small yet impactful improvements.

> [!warning]
> This project is not affiliated with EcoleDirecte or Aplim in any way.

### Highlights

- Dashboard
- Grades average
- Instant averages calculation
- Last grades overview
- Upcoming assignments
- And so much more...

## Getting started

- Install Kolybri from [Google Play](#) _(links coming soon)_
- Log in with your existing EcoleDirecte credentials
- That's it, enjoy!

## Contributing

Kolybri is built with React Native and Expo. Here's how to get set up:

```bash
# install dependencies
npm install

npx expo start
```
